# Proyecto Tienda Online React

Este es un proyecto simple de tienda online desarrollado con React. Permite listar productos, buscar, agregar al carrito, editar y eliminar productos (para usuarios autenticados).

## Funcionalidades

- Listado de productos con búsqueda
- Detalles individuales de productos
- Carrito de compras con cantidad y eliminación
- Login y gestión de usuario (mock)
- Edición y eliminación de productos para usuarios autenticados
- Uso de Bootstrap para diseño responsive

## Instalación y uso

1. Clonar el repositorio  
2. Ejecutar `npm install` para instalar dependencias  
3. Ejecutar `npm start` para iniciar la app en modo desarrollo  
4. Abrir `http://localhost:3000` en el navegador

## Estructura

- `components/` - Componentes React reutilizables  
- `layouts/` - Componentes de página  
- `styles/` - CSS personalizado  
- `App.jsx` - Componente principal  
- `main.jsx` - Punto de entrada

## Notas

- El backend es un servicio mock (MockAPI) para productos  
- La autenticación es simulada  
- Bootstrap incluido para estilos
